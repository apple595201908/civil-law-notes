# 台灣民法筆記｜國考爭點總整理

📖 一套涵蓋**民法總則、物權、消費者保護法**三大領域的國考爭點學習講義，以**單一 HTML 檔案**形式公開免費閱讀，手機、平板、電腦皆可順暢瀏覽。

---

## 📌 專案簡介

本專案整理台灣民法國家考試（律師、司法官、高普考及各類法科考試）的經典爭點，共計：

- **3 大編**：民法總則、物權、消費者保護法
- **11 個 SECTION**（章節）
- **32 個爭點**
- **160 道 Q**（爭點試題）

每一道 Q 皆以國考申論答題體例撰寫，包含四大段落：**法條依據、學說見解、實務判決見解、考試重點結論**。

## ✍️ 每題四段式結構

1. **法條依據**：台灣現行民法、消費者保護法之精確條號與條文內容
2. **學說見解**：甲說／乙說／丙說並陳，涵蓋王澤鑑、陳聰富、謝在全、詹森林等主流權威見解
3. **實務判決見解**：最高法院判例／判決／大法庭裁定之重要見解（含真實案號）
4. **考試重點結論**：答題結論與關鍵記憶點（螢光筆標記）

## 🛠 部署方式（GitHub Pages）

本倉庫已內建 GitHub Actions 自動部署工作流（`.github/workflows/deploy.yml`），只需三個步驟：

1. 進入倉庫 **Settings → Pages**
2. **Source** 選擇 **「GitHub Actions」**
3. 推送到 `main` 分支即自動部署；或到 **Actions** 頁籤手動執行「Run workflow」

等待約 1～2 分鐘，即可於上方網址閱讀。

## 🔄 如何更新內容

- 每次推送到 `main` 分支，工作流即自動重新部署
- 工作流會自指定來源下載最新 `index.html` 並發布至 GitHub Pages
- 若自行維護：將更新後的 HTML 命名為 `index.html` 推送至 `main` 分支根目錄即可（部署來源改為「Deploy from a branch」）
